Guides

Four things worth learning, in order.

Each one is short, and every command in them exists — they were written against the clap definitions in crates/cli/src/main.rs and the tool registry in crates/mcp/src/tools.rs rather than from memory.

1 · Index your first folder

Grant a folder, index it, and read the two numbers people conflate — how many files Marrow knows about, and the much smaller number whose text can actually be quoted.

Read →

2 · Ask a question, follow the citation

Getting from a sentence in an answer to the line in the file it came from, in one click — plus what the sources header is telling you before you open anything.

Read →

3 · Use it from Claude Code or another agent

marrow mcp on stdio, the fourteen tools it exposes, which one to reach for, and the three fields in a result that change how the answer should be read.

Read →

4 · Add a cloud model when you have no GPU

One OpenAI-compatible endpoint, a key that goes into the macOS keychain and nowhere else, and a boundary label on every answer that came from off this machine.

Read →

Search first, model later. Guides 1 and 3 need no model, no GPU and no network at all. Only guides 2 and 4 involve generation, and guide 4 exists precisely so that a machine which cannot run a local model is not shut out.
