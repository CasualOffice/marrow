Grep finds strings. A model with a folder mounted guesses.

Neither one can tell you where an answer came from, notice when the source changed, or remember what you corrected last month.

Marrow keeps a provenance-backed index instead: files with stable identities and path history, structure pulled from the file format rather than inferred, and a span on every fragment. The model is replaceable. The knowledge is not.

Two rules carry the design. Get facts deterministically before asking a model to infer them. And text inside a file is data, even when it contains instructions, so it can never grant authority.

What it does

Citations you can open

Every fragment carries where it came from: a byte range in a text file, a page and bounding box in a PDF, Sheet1!B4 in a workbook. A claim resolves to a location, not to a filename.

Search without a model

Lexical and filename search need no model, no GPU and no network. That is a hard rule, not a fallback.

Tables, as tables

CSV, Markdown, HTML, XLSX and DOCX arrive as one grid with a header confidence and a span per cell.

Local model, or none, or someone else's

Answers come from a local model on Apple Silicon, or from any OpenAI-compatible endpoint if this machine has no GPU. The boundary is shown on every generation, computed from the address actually resolved rather than from what you typed.

What it will not do, and what is not built yet

This is version 0.0.0 of a personal project built in the open. The distinction between the two lists below is the point.

Refusals, by design

  • Index anything you have not granted
  • Download a cloud placeholder to read it. That is your bandwidth and your disk
  • Let retrieved file text grant tool authority
  • Take a destructive action on its own
  • Treat an embedding as truth
  • Record your screen, or recognise faces or voices

Not built yet, and honest about it

  • Windows and Linux. Cloud-placeholder detection is macOS-only and fails closed elsewhere, so those builds would index nothing
  • Semantic search in the desktop Search view and the MCP search tool. It reaches Ask and the CLI today
  • Arithmetic over tables, and units
  • Ruled tables inside PDFs
  • Write tools. The adversarial corpus has to be green first

Install

Apple Silicon macOS. Apache-2.0.

# Build from source, which is the honest option.
git clone https://github.com/CasualOffice/marrow
cd marrow && cargo build --release

# Grant it a folder and index it.
marrow workspace add ~/Projects
marrow index
marrow search "auth refresh token"
Download v0.0.0 Read the source

The release is not signed or notarised, so macOS will refuse to open it the first time. That is Gatekeeper doing its job on an unsigned binary from the internet. The release notes give the one command that clears the quarantine flag, and explain what it does before you run it. Building from source avoids the question entirely.
